# bug-trace2
컴퓨터에서 발생하는 신기하고 이해하기 어려운 오류의 원인과 작동 원리를 분석하는 웹앱
# BUG TRACE

### 컴퓨터는 왜 이런 행동을 할까?

BUG TRACE는 컴퓨터와 스마트폰을 사용하면서 발생하는 신기하고 이해하기 어려운 오류의 원인과 내부 작동 원리를 탐구하는 웹앱입니다.

## 1. 개발 목적

컴퓨터를 사용하다 보면 글자가 갑자기 중복되거나, 소수 계산 결과가 예상과 다르게 나타나거나, 파일의 문자가 깨지는 등 다양한 현상을 경험합니다.

BUG TRACE는 이러한 현상을 단순히 해결하는 데 그치지 않고, 컴퓨터가 데이터를 저장하고 처리하는 방식과 연결하여 오류의 발생 원리를 설명하는 것을 목표로 합니다.

## 2. 주요 기능

- **오류 도감:** 다양한 컴퓨터 오류를 유형별로 검색하고 탐색합니다.
- **원인 해부실:** 오류가 발생하는 과정과 관련 기술을 자세히 설명합니다.
- **현상 실험실:** 실제 연산과 데이터 표현을 통해 일부 현상을 확인합니다.
- **오류 비교실:** 서로 다른 오류의 발생 원인과 특징을 비교합니다.

## 3. 대표 오류 사례

- 한글 입력 중 글자가 중복되는 현상
- 0.1과 0.2를 더했을 때 정확히 0.3이 나오지 않는 현상
- 파일의 글자가 깨져 보이는 현상
- 사진이 다른 기기에서 회전되어 보이는 현상
- 숫자를 정렬했는데 10이 2보다 먼저 나오는 현상
- 브라우저에서 이전 화면이 계속 표시되는 현상

## 4. 개발 환경

- Python
- Streamlit
- GitHub
- Streamlit Community Cloud

## 5. 사용 방법

1. 웹앱에 접속합니다.
2. 오류 도감에서 궁금한 현상을 검색합니다.
3. 오류를 선택해 원인과 내부 작동 원리를 확인합니다.
4. 필요한 경우 현상 실험실에서 관련 계산 결과를 확인합니다.

## 6. 실행 방법

개발 완료 후 다음 명령어로 실행할 예정입니다.

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```
